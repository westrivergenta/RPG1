# 星環のサモナー

物語と戦闘マップが交互に進む、全3話のシミュレーションRPGです。ブラウザだけで遊べます（スマホ対応）。

## 遊び方

- GitHub Pages で公開したURLを開くだけで遊べます。
- スマホでは「ホーム画面に追加」すると、アイコン付きでアプリのように起動できます。
- セーブは遊んでいるブラウザに保存されます。

## 操作

1. 味方をタップ → 青いマスをタップして移動
2. 「攻撃」「魔法」「待機」から行動を選ぶ
3. 最後に向きを決める（側面・背後から攻撃されると不利）

## 主なルール

- 高い位置からの物理攻撃はダメージと命中が上がります。
- 側面からはダメージ120%・命中+20%、背後からはダメージ140%・命中+40%。
- 森は通れません。茂みは通れて、防御と回避が上がります。
- HPが0になった仲間は撤退します。カナタが撤退すると敗北です。

## ファイル

- `index.html` … ゲーム本体（画像もすべて内蔵した1ファイル）
- `icon.png` … アイコン画像
